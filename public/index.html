ssht persistent SSH sessions

Jun – Aug 2026

what
Turns every SSH connection into a resumable tmux session, so work survives sleep, network drops, and switching machines.
hard part
It wraps the system ssh instead of reimplementing it, so ProxyJump, keys, and hardware tokens keep working. A hand-written ~/.ssh/config parser handles Include recursion, Match blocks, and wildcard hosts, and tokio probes hosts concurrently so the fuzzy picker never blocks on a slow one. Optional Mosh transport and local-echo mode for high-latency links.
tech
Rust / tokio / ratatui / SQLite / tmux / mosh
links
GitHub · crates.io

Bare-metal Raspberry Pi 3 kernel

May – Jul 2026

what
A single-core AArch64 kernel for the Raspberry Pi 3 in C and ARMv8 assembly, with no libc, built by following Sergey Matyukevich's raspberry-pi-os lesson series.
hard part
Boot and BSS setup, dropping from EL3/EL2 to EL1, exception vectors and timer IRQs, and a round-robin preemptive scheduler with context switching; then EL0 user processes with system calls (write, malloc, clone/fork, exit) and per-process page tables, where fork copies the parent's user pages. Tested under QEMU.
tech
C / ARMv8 assembly / QEMU
links
GitHub

macwifi Wi-Fi manager for the macOS terminal

Jun – Sep 2026

what
A terminal UI for scanning, joining, and managing Wi-Fi on macOS; a clean-room port of the Linux tool impala.
hard part
Split into a LaunchAgent daemon that owns the CoreWLAN interface and a client that talks to it over a Unix socket, so scans run in a session that gets real network names instead of redacted ones. Speed tests from four backends are normalized into one schema and streamed as JSONL events that other front ends can follow live.

surgraft token-efficient code moves for LLM tools

May – Jul 2026

what
Moves functions between files for LLM coding tools without spending tokens on code that didn't change.
hard part
Locates function boundaries with Python's AST (a regex heuristic for JS/TS), byte-copies the exact range, and only sends the snippet to the model for an optional edit pass. Ships as a CLI, a Python library, and an MCP server.

Python / AST / Claude API / MCP

simdlings learn ARM NEON SIMD by fixing broken kernels

what
A rustlings-style course in C: 24 exercises where you repair broken NEON vector code, then write kernels that must beat the scalar version by 1.6×–3×.
hard part
The test harness is adversarial. Buffers end against a PROT_NONE guard page so a one-byte overread faults immediately, canaries catch negative indexing, every kernel is checked at awkward lengths (0, 1, 3, 17, 1001, ...), and the scalar reference is compiled with autovectorization off so measured speedups are real.
tech
C / ARM NEON / Bash
